HOW TO UPLOAD TO GITHUB
1. Upload the contents of this folder to your GitHub repository.
2. Make sure index.html is in the main/root of the repository.
3. Go to GitHub repository Settings.
4. Open Pages.
5. Choose Deploy from a branch.
6. Select main branch and /root.
7. Save.
8. Open the GitHub Pages link after deployment.

IMPORTANT NOTE
This is a frontend demo version. Data is saved only in the browser used during the presentation.
It does not send real email and does not use a real online database.
This is intentional because GitHub Pages cannot run backend servers.

Update: A neon Back to Top button has been added globally through css/style.css and js/script.js. It appears automatically on every page after scrolling.
